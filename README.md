# Programación Orientada a Objetos (POO) - Proyecto Chorifly

Este espacio contiene el desarrollo específico correspondiente a la asignatatura Programación Orientada a Objetos (POO).

## Archivos de Entrega
  - `flatlaf-3.2.jar`: Este archivo tiene la libreria FlatLaf. Necesaria para la ejecución del programa.
  - `jcalendar-1.4.jar`: Este archivo tiene la libreria JCalendar. Necesaria para la ejecución del programa.
  - `Chorifly v22.0.0.zip`: Este archivo es la versión Final del Proyecto de JAVA + la página web
La ejecución se explica en el main.

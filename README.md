# Análisis de Sistemas - Proyecto Chorifly

Este espacio contiene el desarrollo específico correspondiente a la asignatura Análisis de Sistemas.

## Archivos de Entrega
- `Chorifly - Análisis FODA.pdf`: Este archivo contiene un enlace a un Google Docs con el Análisis FODA del proyecto.
- `Chorifly - Análisis Tecnológico.pdf`: Este archivo contiene un enlace a un Google Docs con el Análisis Tecnológico del proyecto.
- `Chorifly - Computadoras Y Presupuestos`: Este archivo contiene un enlace a un Google Docs con la información de las computadoras y sus respectivos presupuestos.
- `Chorifly - Descripción Problema Solución.pdf`: Este archivo contiene un enlace a un Google Docs con la descripción del problema y la solución propuesta para el proyecto.
- `Chorifly - Diagrama PERT`: Este archivo contiene un enlace a un Google Docs con el Diagrama PERT del proyecto.
- `Chorifly - Diagrama de Gantt`: Este archivo contiene un enlace a un Google Docs con el Diagrama de Gantt del proyecto.
- `Chorifly - Estado del Arte.pdf`: Este archivo contiene un enlace a un Google Docs con el análisis de la competencia y el Estado del Arte del proyecto.
- `Chorifly - MVP.pdf`: Este archivo contiene un enlace a un Google Docs con el Producto Mínimo Viable (MVP) del proyecto.
- `Chorifly - Requisitos Funcionales.pdf`: Este archivo contiene un enlace a un Google Docs con los requisitos funcionales del proyecto.
- `Chorifly - Requisitos no Funcionales.pdf`: Este archivo contiene un enlace a un Google Docs con los requisitos no funcionales del proyecto.
- `Chorifly - SCRUM`: Este archivo contiene un enlace a un Google Docs con el registro de las actividades realizadas durante el desarrollo del proyecto.
- `dfd`: Este archivo contiene un enlace a Google Drive con el Diagrama de Flujo de Datos (DFD) del proyecto.
